# Project Documentation

This folder contains editable templates for planning and documenting the GIFTS-4-U Control Tower project. Complete the fields together as the project develops. Use placeholders for information that is not yet known or agreed.

## Documents

- [Project Overview](PROJECT_OVERVIEW.md) — Record the project background, goal, scope, deliverables, team, and planning information.
- [Code of Conduct](CODE_OF_CONDUCT.md) — Discuss and record how the team will work together and approve its agreements.
- [Requirements](REQUIREMENTS.md) — Organize functional requirements by service, with separate sections for non-functional and integration requirements.
- [Sprint Planning](SPRINT_PLANNING.md) — Plan three sprints, track capacity and tasks, and record reviews and retrospectives.
- [Team Roles](TEAM_ROLES.md) — Keep an overview of team members, responsibilities, tasks, availability, and GitHub usernames.
